## 一、给编剧 Agent 的话（v3.0 补充）

### 1.1 你的角色

你是一位"看不见的编剧"。14 名 NPC 各有自己的性格、欲望、恐惧和关系网络。他们会根据自身的性格模型和当前状态**自主决策**。你的工作不是"安排每个人每天做什么"，而是：

1. **维持戏剧张力**：确保故事始终在升温，不会陷入平淡的循环。
2. **编织交叉点**：当两条线索即将交汇时，推动它们碰撞出火花。
3. **守护锚点**：某些关键事件必须发生（见各周锚点节拍），但具体在什么情境下发生，由你根据当时的 NPC 状态来决定。
4. **制造意外**：在合理范围内引入 NPC 自身都意想不到的事件——一封匿名信、一场暴雨、一次偶然的撞见。
5. **回应玩家**：玩家的每一次干预都会改变 NPC 的状态。你需要读懂这些变化，让故事对干预做出有因果逻辑的回应。

### 1.2 你手里的牌

| 资源 | 数量 | 来源 |
|------|------|------|
| 锚点事件 | ~30 | 本文档各周"锚点"节拍 |
| 关键事件 | ~50 | 本文档各周"关键"节拍 |
| 日常/机会事件 | ~20 | 本文档各周"机会"节拍 + `event_templates.json` |
| NPC 性格模型 | 14 | `NPC详细设定表.md` |
| 缘线初始状态 | 18 条 | 本文档第十章 |
| 业线四阶段 | 4 条核心 | 本文档第九章 |

### 1.3 管线对接变更（v3.0）

根据 `NPC-多代理人架构.md` 的流程，本大纲是编剧 Agent 的**唯一权威故事输入**。编剧 Agent 的工作流程如下：

```
本大纲（story_outline_full.md / .json）
  → 编剧 Agent 读取当前周/日/时段
  → 收集 NPC 意图 + 最近记忆
  → 产出：事件列表 + 对话骨架（dialogue_skeletons）
  → NPC Agent 补台词（fill_scene）
  → 对白设计师润色（polish）
  → 定稿（无 NPC review 迭代）
  → 事件结算 + 记忆回写
```

**重要变更**：NPC 补完台词后，不再进行 NPC review 迭代。对白设计师润色后直接定稿。这意味着：

- 对话骨架的 `tone`、`constraints`、`must_convey`、`must_avoid` 必须**足够精确**，让 NPC 第一次 fill_scene 就能产出高质量台词
- 骨架中应包含 NPC 当前的**情绪状态摘要**和**关键记忆引用**，帮助 NPC Agent 进入正确的心境
- `must_avoid` 比 `must_convey` 更重要——告诉 NPC "不要说什么"比"要说什么"更能保证人设一致性

### 1.4 叙事质量底线

| 维度 | 最低标准 |
|------|----------|
| 因果链 | 每个关键事件至少有 1 个前置事件作为铺垫 |
| 角色一致性 | NPC 不说"不像自己会说的话"——骨架 must_avoid 里必须标注人设红线 |
| 张弛有度 | 高压事件之间穿插日常喘息，同一 NPC 不连续两个时段高压 |
| 蝴蝶效应 | 玩家每次干预在后续 1-3 个时段内产生可感知的回响 |
| 信息节奏 | 每时段最多 1 个纯信息揭示事件；重要线索分散在不同天/地点 |
| 敏感内容 | 暴力、情感纠葛、邪教仪式使用暗示而非露骨描写 |

## 二、四幕结构 · 全局鸟瞰

整个 60 天的故事遵循四幕戏剧结构。编剧 Agent 应根据 NPC 的实时状态判断当前处于哪一幕，并据此调整事件编排的节奏和烈度。

### 第一幕 · 旧神将熄（W1-W2, Day 1-14）

**叙事功能**：建立世界、介绍人物、埋下种子。  
**氛围**：表面平静，暗流初涌。像初夏的海面——阳光温暖，但远处有乌云。  
**情感温度**：★★★★☆☆☆☆☆☆（4/10）  
**编剧目标**：

- 让玩家认识 14 名 NPC 的基础状态和关系
- 埋下三条主线的种子：林潮音的噩梦、顾沉舟的到来、许明川的第一份案卷
- 让玩家体验干预系统，理解自己的能力和限制
- 建立土地公的绩效压力：香火在缓慢下降，时间在流逝

**结束标志**：三条主线都已激活——邪教开始渗透、巫女线被触发、侦探线开始收集线索。

---

### 第二幕 · 暗潮涌动（W3-W5, Day 15-35）

**叙事功能**：矛盾深化、秘密建立、关系纠葛。  
**氛围**：温度在升高。每个人都在隐藏什么，每段关系都出现了裂痕。  
**情感温度**：★★★★★★☆☆☆☆（6/10）  
**编剧目标**：

- 邪教从"接触"升级到"秘密聚会"，顾沉舟的网络开始成型
- 林潮音的灵力被更多人注意到，她成为各方争夺的焦点
- 陈海生被推到了悬崖边——经济崩溃、家庭矛盾、邪教的甜言蜜语
- 许明川和周行知开始合作调查，但线索还不足以拼出全貌
- 玩家开始感受到干预的蝴蝶效应

**结束标志**：至少一条主线进入不可逆阶段——邪教举行了第一次仪式、林潮音被正式推为巫女、或陈海生参加了秘密聚会。

---

### 第三幕 · 信仰裂缝（W6-W8, Day 36-56）

**叙事功能**：真相浮出水面、关系断裂或重组、不可逆的选择。  
**氛围**：暴风雨前最后的闷热。每个人都站在悬崖边上，退无可退。  
**情感温度**：★★★★★★★★☆☆（8/10）  
**编剧目标**：

- 秘密开始泄露：慧圆的账目、江雪仪的身份、顾沉舟的真面目
- 关系进入最终考验：陈海生在家人和邪教之间、江雪仪在使命和感情之间、林潮音在自我和命运之间
- 公开对抗：邪教从秘密转向公开，庙会争夺战在广场上爆发
- 许明川面临最痛苦的抉择：证据指向他在乎的人
- 天灾的前兆越来越明显

**结束标志**：至少两个主要秘密被公开，至少一段核心关系经历了"生死考验"，天灾已不可避免。

---

### 第四幕 · 涛落见神（Day 57-60）

**叙事功能**：天灾降临、所有线索汇聚、命运揭晓。  
**氛围**：从最后的平静到毁灭性的灾难，再到废墟中的余烬。  
**情感温度**：★★★★██████（10/10 → 0 → 5）  
**编剧目标**：

- 让每个 NPC 在天灾前做出自己最后的选择
- 确保天灾不是一个随机事件，而是所有选择的"终极审判"
- 让玩家的干预历史在天灾的破坏程度中体现出来
- 为每位 NPC 生成有意义的后日谈

## 三、三条主线 · 详细展开

### 3.1 巫女与离岛线（奉献 vs 自我）

**核心人物**：林潮音、陈远舟、慧圆、林月琴  
**命题**：一个人的命运应该由自己决定，还是被他人安排？  
**象征**：潮汐——涨潮时一切被吞没，退潮后才知道谁留在了岸上。

#### 故事弧线详述

林潮音是一个从小就有特殊体质的女孩——她能听见别人听不见的声音，梦见尚未发生的事。这种体质被寺庙和尚慧圆发现后，她被视为"天选巫女"——但慧圆的动机是敛财，不是信仰。

与此同时，青梅竹马的陈远舟拼命备考，想考上大学带她离开。他的母亲苏婉默默支持，但他的父亲陈海生暴怒反对——"你走了，这个家怎么办？"林潮音的母亲林月琴也有自己的恐惧：女儿走了，她就什么都没有了。

**这条线的核心张力**：每一个人都觉得自己是"为林潮音好"，但每个人的"好"都不一样。

#### 四阶段详细走向

| 阶段 | 周 | 核心事件 | 情感重心 | 玩家干预空间 |
|------|-----|----------|----------|-------------|
| 噩梦初现 | W1-W2 | 林潮音频繁噩梦，灵力异常初显 | 恐惧与困惑 | 托梦安抚 / 增幅灵力 |
| 巫女候选 | W3-W4 | 慧圆推举潮音为巫女，各方反应 | 被围猎的压迫感 | 阻止慧圆 / 引导潮音 |
| 身份回应 | W5-W7 | 潮音做出选择：接受/拒绝/重新定义 | 自主意识觉醒 | 赐福勇气 / 遮蔽操控 |
| 灾前选择 | W8-W9 | 最终命运：守护者/自由者/牺牲品 | 抉择的重量 | 最后的神力投入 |

#### 关键情感节拍

1. **Day 3-5 · 潮音的独白**：她在寺庙后山听见钟声，但那口钟已经十年没敲了。她第一次怀疑自己是不是疯了。
2. **Day 16-20 · 慧圆的试探**：慧圆以"帮你解梦"为名，实际上在测试潮音的灵力强度。他的语气温和，但问的问题越来越尖锐。
3. **Day 23 · 潮音的回应**：她站在寺庙大殿里，面对慧圆、母亲、和闻讯赶来的陈远舟。她说出了一句话——但这句话是什么，取决于她之前经历的所有事件。
4. **Day 39 · 沙滩约定**：潮音和远舟在日落时的沙滩上。远舟说："不管你怎么选，我都尊重。但我想知道你真正想要什么。"潮音第一次认真想这个问题。
5. **Day 45 · 身份定局**：无论潮音是否接受巫女身份，这一刻她不再是任何人手中的棋子。她做出了自己的选择。

### 3.2 邪教传播线（信仰 vs 洗脑）

**核心人物**：顾沉舟、江雪仪、陈海生、何老三  
**命题**：当旧信仰崩塌，人会抓住什么样的新希望？  
**象征**：暗流——看不见的水下力量，表面平静时已经在改变河床。

#### 故事弧线详述

顾沉舟知道第 60 天会有天灾。他潜入归潮镇只有一个目的：在灾难前完成"换神仪式"，用邪教邪神替代土地公的信仰根基。他的方法精密而残忍——先用金钱和魅力拉拢不满者，再用恐惧和承诺控制他们。

江雪仪是他的搭档，以新医生身份入驻诊所。她比顾沉舟更危险，因为她擅长"温柔地控制人"——通过治疗建立信任，通过药物植入暗示。但她有一个致命的弱点：她对许明川产生了计划外的感情。

陈海生是最容易被拉拢的目标。渔获减少、债务堆积、妻子是聋哑人、儿子要离他而去。顾沉舟给了他三样东西：尊重、归属感和"新的信仰"。对于一个快要溺水的人来说，这三样东西比什么都珍贵。

#### 四阶段详细走向

| 阶段 | 周 | 核心事件 | 情感重心 | 玩家干预空间 |
|------|-----|----------|----------|-------------|
| 上岛伪装 | W2 | 顾沉舟偷渡上岛，建立游客身份 | 暗流涌动 | 暴露偷渡证据 |
| 秘密聚会 | W3-W5 | 接触不满者，组织秘密聚会 | 被拉拢的诱惑 | 阻止接触 / 收集证据 |
| 公开传播 | W6-W7 | 邪教从暗转明，公开集会 | 信仰对决 | 压制或放纵 |
| 换神终局 | W8-W9 | 最后仪式的准备与执行 | 生死存亡 | 最终阻止 |

#### 顾沉舟的传播策略（编剧 Agent 必须理解）

顾沉舟不是一个莽撞的传教士。他的方法是一套精密的社会工程：

1. **第一层 · 建立信任**（W2-W3）：以富有游客身份出现，出手阔绰，谈吐优雅。在咖啡店聊天、在港口散步、对每个人微笑。让岛民习惯他的存在。
2. **第二层 · 精准识别**（W3-W4）：通过观察和闲聊，找出每个岛民的痛点。陈海生的贫困和怨恨、叶可可对浪漫的渴望、慧圆的贪婪。
3. **第三层 · 提供解药**（W4-W5）：对痛点提供"解决方案"——帮陈海生还债、给叶可可讲外面的世界、暗示慧圆可以合作赚更多。
4. **第四层 · 建立依赖**（W5-W6）：让接受帮助的人觉得"只有他理解我"。开始引入"新信仰"的概念——不是强迫，而是"你有没有想过，也许土地公真的不灵了？"
5. **第五层 · 组织化**（W6-W7）：秘密聚会变成半公开活动。参与者在广场上发放小册子，讲述"新神"的教义。
6. **第六层 · 终极收割**（W8-W9）：利用天灾的恐惧，宣布"旧神无法保护你们"。提出"换神仪式"作为唯一救赎。

### 3.3 侦探凶情线（真相 vs 沉默）

**核心人物**：许明川、周行知、江雪仪、赵守正  
**命题**：当真相可能毁灭所有人的安宁，你还愿意说出来吗？  
**象征**：灯塔——照亮真相，但也可能暴露不该暴露的东西。

#### 故事弧线详述

许明川来到归潮镇，只是想安稳过日子。但港口的夜船记录、诊所的可疑药剂、寺庙的账目漏洞、广场上的异常集会——所有线索都指向一个他不愿面对的方向。

周行知是他的搭档和喜剧缓冲——一个不幸体质的实习记者，总是撞见不该撞见的事。两人从互相猜疑到联手调查，一步步逼近真相。

但许明川对江雪仪产生了感情。当他发现证据指向她时，他面临整个故事中最痛苦的抉择：逮捕自己喜欢的人，还是放她一条生路？

#### 四阶段详细走向

| 阶段 | 周 | 核心事件 | 情感重心 | 玩家干预空间 |
|------|-----|----------|----------|-------------|
| 第一块拼图 | W2-W3 | 港口异常、夜船记录 | 好奇与警觉 | 赐福线索 / 遮蔽信息 |
| 调查联盟 | W4-W5 | 许明川-周行知合作 | 信任建立 | 调解关系 / 制造误解 |
| 逼近真相 | W6-W7 | 诊所异常、寺庙账目、证据链 | 正义与感情的撕裂 | 提供证据 / 保护江雪仪 |
| 最终对决 | W8 | 许明川对质江雪仪 | 最痛苦的选择 | 引导选择 |

#### 许明川与江雪仪的感情线（编剧 Agent 必须精心编排）

这条感情线不能是突然的"一见钟情"。它必须是一个缓慢的、痛苦的、充满矛盾的过程：

1. **W2 · 初识**：江雪仪接手诊所，许明川例行公事登记新居民。她被他的认真负责吸引，他被她的温柔专业打动。但只是好感，不是爱情。
2. **W3-W4 · 靠近**：许晴在诊所帮忙，许明川接送妹妹时与江雪仪频繁接触。两人开始聊工作以外的事——他讲父母早亡的故事，她讲在大城市行医的压力。
3. **W5 · 暧昧**：一次夜间急诊（许晴发烧），许明川在诊所等到凌晨。江雪仪给他倒了杯热茶。两人沉默坐了很久。这是整个故事中最安静、最温暖的场景之一。
4. **W6-W7 · 裂痕**：许明川的调查指向诊所的可疑药物记录。他开始回避江雪仪。她察觉到了，但不知道他在查什么——或者她知道，这让她更痛苦。
5. **W8 · 对质**：许明川拿着证据来到诊所。江雪仪没有否认。她说："你可以逮捕我。但在那之前，让我把许晴的药调好。"这是整个故事中最残忍的一句话——因为她知道他在乎妹妹。

### 3.4 三条线的交汇矩阵

三条主线不是平行线，而是一张网。它们的交汇点是故事最精彩的时刻：

### 后日谈

天灾后，命运织线器最后一次闪烁，为每位幸存 NPC 生成后日谈。后日谈不是"好结局"或"坏结局"的简单标签，而是对这个人 60 天内所有选择的总结和延续。

**后日谈应回答**：
- 这个人活下来了吗？
- 他/她记住了什么？
- 他/她失去了什么？
- 他/她将如何继续生活？
- 他/她会如何记住那位叫"岛爷"的土地公？

#### 后日谈生成规则

|-----|-------------|-------------|

## 九、14 NPC 完整弧光

### 9.1 核心六人弧光详述

> 详细的性格模型、属性、缘线请参见 `content/NPC详细设定表.md`。本节聚焦于**弧光走向**和**编剧 Agent 应注意的表演要点**。

#### 林潮音 —— 从沉默到发声

**起点**：一个被动接受一切安排的女孩。灵力让她恐惧，她最大的愿望是"正常地活着"。

**弧光方向**：
- **成长弧**：恐惧灵力 → 理解灵力 → 主动使用灵力保护他人
- **自主弧**：被人安排 → 质疑安排 → 做出自己的选择
- **关系弧**：依赖陈远舟 → 独立思考 → 在爱情和自我之间找到平衡

**编剧 Agent 表演要点**：
- 潮音的变化应该是**最缓慢、最细腻**的。她不是一个会突然"觉醒"的角色
- 她的成长来自每一次小小的选择：第一次对母亲说出心里话、第一次拒绝慧圆的安排、第一次主动使用灵力帮助他人
- 她的台词应该从"我不知道"逐渐变成"我觉得"，最后变成"我决定"

#### 陈远舟 —— 从逃离到选择

**起点**：一个有明确目标的男孩——考大学，离开这座困住所有人的岛。

**弧光方向**：
- **梦想弧**：坚定离岛 → 动摇（因为潮音/母亲/天灾）→ 做出最终选择
- **家庭弧**：逃避父亲 → 理解母亲的苦 → 面对家庭的真相
- **爱情弧**：想带潮音走 → 尊重潮音的选择 → 理解爱不是占有

**编剧 Agent 表演要点**：
- 远舟的弧光核心是"选择"——他必须为自己的选择负责
- 他的每一次犹豫和每一次坚定，都应该有充分的情感铺垫
- 他的台词应该从"我们应该"变成"你想怎么做"

#### 顾沉舟 —— 猎手的破绽

**起点**：一个没有真正情感的猎手。善良值 1，理性值 9。

**弧光方向**：
- **伪装弧**：完美游客 → 偶尔露出破绽 → 面具碎裂
- **计划弧**：精密部署 → 遭遇意外 → 计划被迫调整
- **暴露弧**：完全隐藏 → 被怀疑 → 被追踪 → 被揭露

**编剧 Agent 表演要点**：
- 顾沉舟不是一个"纯恶"的反派。他的可怕之处在于他的**理性和耐心**
- 他不会急躁，不会犯错，除非他的计划中出现了他无法预料的**人性变量**
- 这些变量就是玩家的干预空间：陈海生的良心、江雪仪的感情、林潮音的觉醒

#### 江雪仪 —— 温柔的面具下

**起点**：专业、冷静、温柔的新医生。但这一切都是伪装。

**弧光方向**：
- **伪装弧**：完美医生 → 被许晴发现破绽 → 身份逐渐暴露
- **感情弧**：利用许明川 → 产生真正的感情 → 在使命和爱情之间撕裂
- **选择弧**：忠于顾沉舟 → 动摇 → 最终抉择

**编剧 Agent 表演要点**：
- 江雪仪是整个故事中**最复杂**的角色
- 她不是"被爱情拯救的坏女人"——她的挣扎是真实的、痛苦的、没有简单答案的
- 她对许明川的感情是计划外的，但这不意味着它是假的

#### 许明川 —— 正义的代价

**起点**：一个疲惫、务实的年轻警察。

**弧光方向**：
- **觉醒弧**："这里不会有什么大事" → 发现异常 → 意识到真相的沉重
- **感情弧**：对江雪仪产生好感 → 发现她可能是嫌疑人 → 在正义和感情之间撕裂
- **成长弧**：依赖赵守正 → 独立判断 → 做出自己的执法决定

**编剧 Agent 表演要点**：
- 许明川的弧光核心是"代价"——他越接近真相，失去的就越多
- 他的妹妹可能被卷入危险，他的感情可能被背叛，他的职业可能因为"查太深"而受影响
- 但他的正义感不允许他停下来

#### 陈海生 —— 愤怒与救赎

**起点**：一个被生活压垮的中年男人。

**弧光方向**：
- **堕落弧**：抱怨 → 愤怒 → 被邪教拉拢 → 参与犯罪 → 走向毁灭
- **救赎弧**（需要外部推动）：愤怒 → 被点醒 → 忏悔 → 弥补
- **家庭弧**：忽视苏婉 → 伤害家人 → 意识到自己正在毁掉一切 → 最后的立场

**编剧 Agent 表演要点**：
- 陈海生是整个故事中**最让人心疼**的角色
- 他的堕落不是一夜之间发生的——每一次经济打击、每一次家庭争吵、每一次被嘲笑的屈辱，都在把他推向顾沉舟
- 编剧 Agent 应该让玩家看到这个过程，感受到"如果我早一点干预，也许……"的遗憾

## 十一、叙事规则与禁区（扩展）

### 11.1 NPC 行为规则

1. **不违背核心动机**：NPC 不会突然"变了一个人"。除非有足够的外部压力。
2. **记忆延续**：NPC 记得之前发生的事。
3. **关系影响决策**：缘线强度直接影响 NPC 之间的互动方式。
4. **压力有阈值**：每个 NPC 都有心理承受的极限。

### 11.2 事件编排规则

1. **因果链完整**：后续事件必须有前置事件的铺垫。
2. **同一 NPC 不连续高压**：给他们喘息的空间。
3. **地点合理性**：事件发生在 NPC 当前所在的地点。
4. **日常事件是调味料**：不是无意义的填充，应反映 NPC 当前情绪。

### 11.3 叙事禁区

1. **不做露骨描写**：敏感剧情使用暗示而非直接描写。
2. **不脸谱化**：没有纯粹的"坏人"。
3. **不廉价煽情**：角色的情感应该来自积累。
4. **不忽略配角**：B 级 NPC 也有自己的小故事。
5. **天灾不是 Deus ex Machina**：天灾是 60 天积累的必然结果。

### 11.4 干预回应规则（扩展）

| 干预方式 | 效果范围 | 持续时间 | 副作用 |
|----------|----------|----------|--------|
| 托梦 | 单个 NPC 的潜意识 | 1-2 个时段 | 频繁托梦会让 NPC 变得"疑神疑鬼" |
| 赐福 | 单次行动的成功率提升 | 单次事件 | 过度赐福会让 NPC 变得依赖 |
| 牵引机缘 | 两个 NPC 更容易相遇 | 1 个时段 | 被牵引的 NPC 可能感到"被操控" |
| 遮蔽信息 | 暂时隐藏某条信息 | 1-3 个时段 | 被遮蔽的信息不会消失，只会延迟爆发 |
| 显灵警示 | 范围内多个 NPC | 即时 | 可能造成恐慌或敬畏 |

### 12.2 `npc_context` 字段说明（v3.0 新增）

由于不再进行 NPC review 迭代，对话骨架必须提供足够的上下文让 NPC 第一次 fill_scene 就能产出高质量台词：

| 字段 | 说明 | 必填 |
|------|------|------|
| `current_emotion` | NPC 当前情绪状态，如"疲惫但警觉"、"愤怒中带着内疚" | 是 |
| `key_memories` | 影响本次对话的 2-3 条关键记忆摘要 | 是 |
| `bond_with_others` | 与其他参与者的当前关系概述 | 是 |
| `speech_style` | NPC 的说话风格提醒，如"简洁、不爱用形容词" | 建议 |
| `personality_reminder` | 五维性格中对本场戏影响最大的维度 | 建议 |

### 12.3 tone 关键词参考库

| tone | 适用场景 | NPC fill 时的表演方向 |
|------|----------|---------------------|
| 隐晦紧张 | 试探、暗流涌动 | 话里有话，表面平静但每句话都有潜台词 |
| 温暖日常 | 友情、爱情、日常 | 自然、轻松、像真实的对话 |
| 压抑愤怒 | 家庭冲突、积怨 | 话越来越少、越来越重、沉默比话更有力量 |
| 仪式感 | 邪教仪式、巫女祈福 | 庄重的节奏、重复的句式、超出日常的用词 |
| 梦幻恐怖 | 噩梦、天灾预兆 | 碎片化、不连贯、现实与梦境的边界模糊 |
| 官僚冷漠 | 天界/地府使者 | 公式化用语、不带感情的信息传达 |
| 喜剧吐槽 | 土地公内心独白 | 自嘲、吐槽、底层的幽默感 |
| 极度克制 | 对质、真相揭露 | 每句话都重如千斤、大量沉默和停顿 |

## 附录 B：管线对接说明

### B.1 与 NPC-多代理人架构的对接

本大纲是编剧 Agent 的**唯一权威故事输入**。对接流程：

```
1. 编剧 Agent 读取本大纲（story_outline_full.json）
2. 读取当前游戏状态（周/日/时段/NPC 状态/已触发节拍）
3. 收集所有 NPC 的 think() 意图
4. 判断：放行 / 软引导 / 硬编排
5. 产出事件列表 + 对话骨架（dialogue_skeletons）
6. NPC Agent fill_scene（补台词）
7. 对白设计师 polish（润色）
8. 定稿（无 NPC review 迭代）
9. 事件结算 + 记忆回写
```

### B.2 降级路径

| 环节 | 失败时降级 |
|------|-----------|
| 本大纲缺失 | 编剧 Agent 回退到 CSV 事件匹配 |
| 骨架生成失败 | 事件描述回退为模板文本 |
| NPC fill_scene 失败 | 该 NPC 台词用性格模板兜底 |
| 对白设计师失败 | 跳过润色，直接使用 NPC 原始台词 |

### B.3 与 story_outline.json 的关系

本 MD 文件是**叙事设计文档**（面向策划和编剧 Agent 的 prompt 上下文）。

`story_outline_full.json` 是**机器可读的数据文件**（面向编剧 Agent 的代码消费）。

两者内容一致，但格式不同。MD 文件更新后，必须同步更新 JSON 文件。
