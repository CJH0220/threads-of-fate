# UI 规格：人物面板

> 文档状态：v1.1（2026-07-14 前端重构同步）
> 前次版本：初稿（2026-06-10）
> 所属阶段：P0
> 引擎方向：Godot
> 美术方向：简约像素风

## 更新说明（v1.1）

新增「托梦入口」（§12）：夜晚且今日未托梦时，人物面板顶部出现「托梦」按钮，点击弹出文本对话框，输入梦境后消耗 3 神力向该 NPC 写入一条记忆。规则以 `system/神力干预系统.md §5.1` 为准。

---

## 1. 用途

人物面板用于查看单个 NPC 的身份、当前状态、今日行程、关系缘线和业线进度。它帮助玩家判断这个角色是否值得关注、是否存在风险，以及是否需要干预。

---

## 2. 入口与出口

### 入口

| 来源 | 触发 |
|---|---|
| 主地图 | 点击人物头像 / 标记 |
| 地点面板 | 点击今日人物列表 |
| 事件面板 | 点击参与角色头像 |
| 缘线视图 | 点击关系对象 |
| 业线视图 | 点击角色条目 |

### 出口

| 操作 | 结果 |
|---|---|
| 关闭按钮 | 返回上一层 |
| Esc | 返回上一层 |
| 点击相关地点 | 关闭或跳转地点面板 |
| 点击相关事件 | 跳转事件详情或事件推进面板 |

---

## 3. 布局规格

```text
┌──────────────────────────────────────────────┐
│ 头像 / 姓名 / 身份       [托梦]* [关闭]       │
├──────────────────────────────────────────────┤
│ 简介：2-3 句人物描述                         │
├─────────────────────┬────────────────────────┤
│ 今日行程             │ 当前状态               │
│ 早：学校             │ 心智 6                 │
│ 午：商业街           │ 体魄 4                 │
│ 晚：寺庙             │ 魅力 7                 │
│                     │ 信仰 5                 │
├─────────────────────┴────────────────────────┤
│ 缘线：陈远舟 友情 Lv.3 / 顾沉舟 利益 Lv.2     │
├──────────────────────────────────────────────┤
│ 业线：主业线 [■■■■□□] 65% 当前节点：……       │
└──────────────────────────────────────────────┘
```

`[托梦]*` = v1.1 新增按钮，仅在**夜晚**且**当日托梦配额未用**时显示为可点击状态；其它时段或已用时按钮灰化，Hover 显示原因。

---

## 4. 组件清单

| 组件 | 类型 | 内容 | 交互 |
|---|---|---|---|
| 人物头像 | `TextureRect` | 像素头像 | 无 |
| 姓名身份 | `Label` | 姓名、职业、年龄可选 | 无 |
| 简介区 | `RichTextLabel` | 简短人物描述 | 可滚动 |
| 今日行程 | 列表 | 早/午/晚地点 | 点击地点跳转地点面板 |
| 当前状态 | 图标 + 数值 | 心智、体魄、魅力、信仰 | Hover 解释 |
| 缘线列表 | 列表 | 关系对象、性质、等级 | 点击对象跳转人物面板 |
| 业线摘要 | 进度条 + 文本 | 主业线、支线进度 | 点击查看业线视图 |
| **托梦按钮**（v1.1） | `Button` | 「托梦」文本 + 神力消耗提示 | 点击弹出托梦对话框；夜晚+未用时可点，其它态灰化 |
| 关闭按钮 | `Button` | 返回 | 关闭面板 |

---

## 5. 信息优先级

1. 姓名、头像、身份
2. 今日行程
3. 当前状态
4. 缘线关系
5. 业线进度
6. 详细简介和历史记忆

MVP 不展示完整 Agent Memory，只显示系统整理后的简短摘要。

---

## 6. 缘线展示

| 字段 | 示例 |
|---|---|
| 对象 | 陈远舟 |
| 关系性质 | 友情 |
| 等级 | Lv.3 |
| 强度 | 65 / 100，可隐藏具体数值 |
| 近期变化 | +5，可选 |

颜色规则：

| 关系 | 颜色 |
|---|---|
| 爱情 | 红 / 粉 |
| 友情 | 蓝 |
| 利益 | 金 |
| 陌生 | 灰 |
| 仇恨 | 黑 / 暗红 |

---

## 7. 业线展示

| 字段 | 内容 |
|---|---|
| 主业线名称 | 如“离开小镇” |
| 当前进度 | 0%–100% |
| 当前节点 | 当前正在推进的关键事件 |
| 风险提示 | 若有危险节点，显示红色警告 |
| 支线数量 | 显示支线入口 |

MVP 表现：进度条 + 当前节点一句话。  
后续表现：业线树或时间线。

---

## 8. 状态与变体

| 状态 | 表现 |
|---|---|
| 正常 | 展示完整人物信息 |
| 未解锁人物 | 头像暗化，显示“尚未了解此人” |
| 无缘线 | 显示“暂无明确关系” |
| 无业线 | 显示“命运尚未显形” |
| 危险状态 | 人物头像或业线区域显示红色警告 |
| 数据缺失 | 显示兜底文本，不阻塞界面 |

## 11. 验收标准

- [ ] 点击地图人物后能打开对应人物面板。
- [ ] 人物面板显示头像、姓名、身份和简介。
- [ ] 今日早/午/晚行程显示正确。
- [ ] 当前状态至少显示 4 个核心属性。
- [ ] 缘线列表能显示关系对象、关系类型和强度。
- [ ] 点击缘线对象能跳转到对应人物面板。
- [ ] 业线区域能显示主业线名称、进度和当前节点。
- [ ] 无缘线、无业线、未解锁人物都有明确空状态。
- [ ] **v1.1**：夜晚 + 当日未托梦时，「托梦」按钮可点击；其它态灰化并显示原因。
- [ ] **v1.1**：点击「托梦」弹出文本对话框，取消不扣神力；确认时扣 3 神力、写入 NPC 记忆、Toast「梦境已投递」、按钮切换为「今夜已托梦」灰态。
- [ ] **v1.1**：托梦当次结束后，任何其它 NPC 的人物面板托梦按钮同步灰化（日内配额共享）。

## 12. 托梦入口（v1.1 新增）

### 12.1 显示逻辑

| 条件 | 按钮态 | Hover 提示 |
|---|---|---|
| 当前时段 = 夜晚 且 当日未托梦 且 神力 ≥ 3 | 可点击 | 「向 {NPC 姓名} 托梦（消耗 3 神力）」 |
| 当前时段 ≠ 夜晚 | 灰化 | 「托梦仅在夜晚可用」 |
| 当日已托梦 | 灰化 | 「今夜已托梦，明日再来」 |
| 神力 < 3 | 灰化 | 「神力不足（需 3）」 |
| NPC 未解锁 | 不显示 | — |

### 12.2 托梦对话框

```text
┌──────────────────────────────────────┐
│ 向 林潮音 托梦                 [×]   │
├──────────────────────────────────────┤
│ 神力 15 → 12 · 今夜唯一一次          │
├──────────────────────────────────────┤
│ [文本框，多行，占位「让她梦见……」]    │
│                                      │
├──────────────────────────────────────┤
│                    [取消]  [投递梦境] │
└──────────────────────────────────────┘
```

规则：

- 文本框允许空但不推荐；空文本仍会写入一条通用梦境记忆。
- 提交后**不能撤销**。
- 文本长度上限建议 80 字。
- 敏感词按 `system/AI生成边界.md` 与 `system/事件系统.md §10.3` 过滤。

### 12.3 结果反馈

| 时机 | 反馈 |
|---|---|
| 提交完成 | Toast「梦境已投递给 {NPC 姓名}」 |
| 面板刷新 | 人物面板托梦按钮转为「今夜已托梦」灰态 |
| NPC 后续行为 | 由 NPC think 阶段读取记忆自行解释，可能改变对话/事件倾向；**不在面板上直接展示托梦对属性/情绪的影响** |

### 12.4 与其它系统的关系

- 消耗立即由 `system/资源系统.md` 扣除。
- 记忆写入由 NPC 记忆系统承载（`src/backend/ai/npc_agent/NPCAgent记忆系统设计.md`），记忆条目 tag 为 `dream_from_land_god`。
- 记忆的检索与遗忘曲线与其它记忆一致，不做特殊保护。

### 12.5 前端实现锚点

- 组件：`godot/scenes/ui/DreamTextDialog.tscn` + `godot/scripts/ui/dream_text_dialog.gd`
- 状态服务方法：`state.apply_dream(npc_id, dream_text)`
- 面板信号：`CharacterPanel.dream_requested(npc_id, display_name)` 由 `MainGameUI` 转接到对话框
